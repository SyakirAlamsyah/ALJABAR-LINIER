## UAS ALJABAR LINIER - PROGRAM ANALISIS 2 VEKTOR
Program ini merupakan tugas proyek mata kuliah Aljabar Linier. Program ini dibuat untuk operasi dan analisis vektor Euclidean di ruang $\mathbb{R}^n$. Program akan menerima dua vektor di ruang $\mathbb{R}^n$ dengan $n \leq 10$. Program dapat menghitung Norma Euclidean dari kedua vektor tersebut beserta dot productnya dan membuat analisis apakah vektor sejajar, tegak lurus (ortogonal), atau membentuk sudut tertentu
